Menu bar header — in-canvas (GLUT)

OS title bar is out of reach in GLUT, so everything must live inside the scene window. The design reclaims that constraint: a menu bar along the very top replaces the current button row, the status and error live in a thin footer strip along the bottom (where the existing bottom error message already is), and the floating Variables panel stays as a draggable overlay. Three sub-variations below — same skeleton, different error treatment and menu handling.

A
Baseline: menu bar + footer
Top: brand mark + primary menus + Replay as a visually-weighted primary action, then Search. Bottom: single status strip absorbs the current F1/cmds/Ln readout and the yellow error message.
