Interactive OpenGL immediate-mode REPL - type GL commands, press `;`, watch geometry render live.

## Downloads

| Platform | Artifact | Notes |
|---|---|---|
| macOS (universal) | `gl-repl-v0.1-macos.zip` | arm64 + x86_64 - Apple Silicon and Intel |
| Linux (x86_64) | `gl-repl-v0.1-linux-x86_64.tar.gz` | needs system OpenGL + GLUT/freeglut |

Both bundle an 18-track music pack. `make fetch-music` pulls the full pack.

## macOS: first launch

The app is **ad-hoc signed**, not signed with a paid Apple Developer ID, so
Gatekeeper shows an "unidentified developer" prompt the first time:

1. Unzip, move `gl-repl.app` to `/Applications` (or anywhere).
2. **Right-click the app → Open**, then confirm in the dialog.
   A plain double-click won't offer the bypass.
3. If macOS still refuses: **System Settings → Privacy & Security**, scroll to
   the bottom, and click **Open Anyway**.

Only step 1 is needed after that - the choice is remembered.

Should you ever see *"gl-repl.app is damaged and can't be opened"*, that means
the download was corrupted (that message is Gatekeeper's response to a broken
or missing signature, not a real disk problem). Re-download, or clear the
quarantine flag manually:

```sh
xattr -dr com.apple.quarantine /Applications/gl-repl.app
```

## Linux

Run from inside the extracted directory so the bundled music is found:

```sh
tar xzf gl-repl-v0.1-linux-x86_64.tar.gz
cd gl-repl-v0.1-linux-x86_64
./gl-repl
```

Needs the OpenGL + GLUT runtime libraries - on Debian/Ubuntu:
`sudo apt install libgl1 libglu1-mesa freeglut3`.

Run with `--no-audio` to skip audio init entirely.

## Getting started

Press <kbd>F1</kbd> for help. `;` commits the current line, <kbd>Enter</kbd>
inserts a new one, <kbd>F12</kbd> cycles the built-in examples,
<kbd>Ctrl</kbd>+<kbd>R</kbd> replays the program step by step.
