Patch release. **Linux users should upgrade** - v0.1's Linux binary aborts on
any managed-workspace operation.

## Fixes

**Linux: crash on every managed-workspace operation.** `glr_paths_same_dir()`
gave `realpath()` a 1024-byte buffer. glibc's `_FORTIFY_SOURCE` checks that
buffer against `PATH_MAX` (4096) and aborts the process when it is smaller -
and the check is on the buffer, not the path, so it fired unconditionally,
even resolving a four-character path. The v0.1 Linux binary was built
fortified, so opening a workspace while another was open, or any workspace
list lookup with a workspace open, ended in:

```
*** buffer overflow detected ***: terminated
```

macOS has no fortified `realpath`, so the v0.1 macOS build was never affected.

**Code panel: stale hit-testing after a layout change.** The row cache shared
between rendering and hit-testing identified a snapshot by its address alone.
Snapshots are stack values, so a later one could land on a retired one's
address and inherit a builder laid out for the wrong panel rect - statusbar
chips then stopped responding to clicks until the next render. Snapshots now
carry a build serial and the cache keys on it.

## macOS: first launch

The app is **ad-hoc signed**, not signed with a paid Apple Developer ID, so
Gatekeeper shows an "unidentified developer" prompt the first time:

1. Unzip, move `gl-repl.app` to `/Applications` (or anywhere).
2. **Right-click the app → Open**, then confirm in the dialog.
   A plain double-click won't offer the bypass.
3. If macOS still refuses: **System Settings → Privacy & Security**, scroll to
   the bottom, and click **Open Anyway**.

Only step 1 is needed after that - the choice is remembered.

Should you ever see *"gl-repl.app is damaged and can't be opened"*, that means
the download was corrupted (that message is Gatekeeper's response to a broken
or missing signature, not a real disk problem). Re-download, or clear the
quarantine flag manually:

```sh
xattr -dr com.apple.quarantine /Applications/gl-repl.app
```

## Linux

Run from inside the extracted directory so the bundled music is found:

```sh
tar xzf gl-repl-v0.1.1-linux-x86_64.tar.gz
cd gl-repl-v0.1.1-linux-x86_64
./gl-repl
```

Needs the OpenGL + GLUT runtime libraries - on Debian/Ubuntu:
`sudo apt install libgl1 libglu1-mesa freeglut3`.

Run with `--no-audio` to skip audio init entirely.

## Getting started

Press <kbd>F1</kbd> for help. `;` commits the current line, <kbd>Enter</kbd>
inserts a new one, <kbd>F12</kbd> cycles the built-in examples,
<kbd>Ctrl</kbd>+<kbd>R</kbd> replays the program step by step.
